# 🎨 DevMatch - Frontend (UI)

Este módulo contiene la interfaz de usuario de DevMatch, orientada a permitir la exploración de proyectos, postulaciones y gestión de perfiles de usuario.

**Owner del Frontend:** Ximena.

## 🛠️ Stack Tecnológico
* **Core:** React + Vite.
* **Lenguaje:** TypeScript.
* **Estilos:** CSS (Figma definido en el SRS).

## 🚀 Configuración Local

1. **Asegura la versión de Node:**
   * Utiliza la versión definida en el `.nvmrc` del proyecto.
   ``bash
   nvm install(solo si no la tienes)
   nvm use

2. **Instalar dependencias:**
   ```bash
   cd frontend
   npm install

3. **Levantar el entorno de desarrollo**
    ``bash
    npm run dev
